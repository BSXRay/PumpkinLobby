# Local builds (Windows x64 & Linux x64 .deb)

This is a patched checkout of [Pumpkin](https://github.com/Pumpkin-MC/Pumpkin).

## Patches
See `patches/` for the applied changes (disable gameplay features + build tooling).

## Build
Windows x64:
```
.\build-windows.ps1
```
Linux x64 .deb (cross-built from Windows):
```
.\build-linux-deb.ps1
```
